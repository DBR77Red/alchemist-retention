How do you "win" a challenge?

You've run the simulation — what does the result screen look like?

A

Pass / Fail

Each challenge has hard targets. Hit all of them → you pass and unlock the next. Miss any → fail and try again. Clean, binary, no ambiguity.

Example: "D7 ≥ 18% AND ARPU ≥ $1.20 AND churn spike < day 3"

B

Letter Grade (S / A / B / C / F)

Each challenge scores you across multiple dimensions. You need at least a C to unlock the next, but S-rank requires truly optimized play. Encourages replaying for perfection.

Example: Retention B+ · Revenue A · Balance C → overall B"

C

Weighted Score (0–100)

A single numeric score per run, calculated from a weighted formula across all metrics. A threshold score unlocks the next challenge. High scores go on a personal best board.

Example: "Score: 74 / 100 — Unlock threshold: 60 — Personal best: 81"
